# Works 页面改造方案：长滚动 + 项目自动加载

## 1. 方案目标

- 将现有 `Works` 页面改造成**全屏滚动展示**（每屏一个项目），滚动时自动吸附。
- 右侧（或下方）显示项目的 **UI 模拟器**（手机 / 浏览器外壳），预览 `preview.html`。
- **完全分离数据**：以后添加项目只需在 `public/works-data/` 下新建文件夹，放入 `meta.json` 和 `preview.html`，运行脚本即可，**无需修改任何 React 代码**。
- **首次加载显示骨架屏**，无数据时显示友好的空状态引导。

## 3. 新增自动扫描脚本 `scripts/generate-works.js`

**作用**：遍历 `public/works-data/` 下的所有子目录，读取 `meta.json`，生成 `manifest.json`。

```javascript
// scripts/generate-works.js
const fs = require('fs');
const path = require('path');

const dataDir = path.join(__dirname, '../public/works-data');
const outputFile = path.join(dataDir, 'manifest.json');

// 确保目录存在
if (!fs.existsSync(dataDir)) {
  fs.mkdirSync(dataDir, { recursive: true });
}

const projects = fs.readdirSync(dataDir)
  .filter(f => {
    const fullPath = path.join(dataDir, f);
    return fs.statSync(fullPath).isDirectory() && f !== 'manifest.json';
  })
  .map(folder => {
    const folderPath = path.join(dataDir, folder);
    const metaPath = path.join(folderPath, 'meta.json');
    const previewPath = path.join(folderPath, 'preview.html');
    const coverPath = path.join(folderPath, 'cover.png');

    let meta = {};
    if (fs.existsSync(metaPath)) {
      meta = JSON.parse(fs.readFileSync(metaPath, 'utf-8'));
    }

    const hasPreview = fs.existsSync(previewPath);
    const previewUrl = hasPreview ? `/works-data/${folder}/preview.html` : '';

    return {
      id: folder,
      title: meta.title || folder,
      subtitle: meta.subtitle || '',
      description: meta.description || '',
      techStack: meta.techStack || [],
      displayType: meta.displayType || 'browser', // 'mobile' 或 'browser'
      demoUrl: meta.demoUrl || '',
      githubUrl: meta.githubUrl || '',
      previewUrl: previewUrl,
      coverImage: fs.existsSync(coverPath) ? `/works-data/${folder}/cover.png` : ''
    };
  });

fs.writeFileSync(outputFile, JSON.stringify(projects, null, 2));
console.log(`✅ 已生成 manifest.json，共 ${projects.length} 个项目。`);
```

**在 `package.json` 中添加脚本**：
```json
"scripts": {
  "generate-works": "node scripts/generate-works.js"
}
```

## 4. 改造 `src/pages/Works.jsx`

- 加载 `manifest.json` 显示项目列表。
- 加载中显示**骨架屏**（3 个占位卡片）。
- 无数据时显示**空状态**引导。
- 有数据时渲染全屏滚动项目，包含 UI 模拟器。

```jsx
// src/pages/Works.jsx
import { useEffect, useState, useRef } from 'react';
import '../styles/pages/works.css';

// 骨架卡片组件
const SkeletonCard = () => (
  <div className="skeleton-section">
    <div className="skeleton-content">
      <div className="skeleton-info">
        <div className="skeleton-title"></div>
        <div className="skeleton-subtitle"></div>
        <div className="skeleton-desc"></div>
        <div className="skeleton-tags">
          <span></span><span></span><span></span>
        </div>
        <div className="skeleton-actions">
          <span></span><span></span>
        </div>
      </div>
      <div className="skeleton-mockup">
        <div className="skeleton-browser"></div>
      </div>
    </div>
  </div>
);

export default function Works() {
  const [projects, setProjects] = useState([]);
  const [loading, setLoading] = useState(true);
  const containerRef = useRef(null);

  useEffect(() => {
    fetch('/works-data/manifest.json')
      .then(res => {
        if (!res.ok) throw new Error('manifest not found');
        return res.json();
      })
      .then(data => {
        setProjects(data);
        setLoading(false);
      })
      .catch(() => {
        setProjects([]);
        setLoading(false);
      });
  }, []);

  if (loading) {
    return (
      <div className="works-container skeleton-container">
        <SkeletonCard />
        <SkeletonCard />
        <SkeletonCard />
      </div>
    );
  }

  if (!projects.length) {
    return (
      <div className="works-empty-state">
        <div className="empty-icon">📭</div>
        <h2>还没有作品</h2>
        <p>
          请在 <code>public/works-data/</code> 目录下创建项目文件夹，
          每个文件夹包含 <code>meta.json</code> 和 <code>preview.html</code>，
          然后运行 <code>npm run generate-works</code> 生成清单。
        </p>
        <div className="empty-example">
          <p>示例文件夹结构：</p>
          <pre>
            {`public/works-data/
  └── my-project/
      ├── meta.json
      ├── preview.html
      └── cover.png (可选)`}
          </pre>
        </div>
      </div>
    );
  }

  return (
    <div className="works-container" ref={containerRef}>
      {projects.map((project, index) => {
        const isMobile = project.displayType === 'mobile';
        const tags = (project.techStack || []).map(t => <span key={t}>{t}</span>);

        return (
          <section key={project.id} className="works-section" data-index={index}>
            <div className="works-content">
              <div className="works-info">
                <h1>{project.title}</h1>
                {project.subtitle && <div className="works-subtitle">{project.subtitle}</div>}
                <p className="works-desc">{project.description}</p>
                <div className="works-tech">{tags}</div>
                <div className="works-actions">
                  {project.demoUrl && (
                    <a href={project.demoUrl} target="_blank" rel="noopener noreferrer">
                      🔗 在线体验
                    </a>
                  )}
                  {project.githubUrl && (
                    <a href={project.githubUrl} target="_blank" rel="noopener noreferrer" className="github">
                      🐙 源码
                    </a>
                  )}
                </div>
              </div>
              <div className="works-mockup">
                {project.previewUrl ? (
                  <>
                    {isMobile ? (
                      <div className="phone-frame">
                        <div className="phone-notch"></div>
                        <div className="phone-screen">
                          <iframe src={project.previewUrl} loading="lazy" title={project.title}></iframe>
                        </div>
                      </div>
                    ) : (
                      <div className="browser-frame">
                        <div className="browser-bar">
                          <div className="browser-dots"><span></span><span></span><span></span></div>
                          <div className="browser-url">{project.demoUrl || 'localhost'}</div>
                        </div>
                        <div className="browser-body">
                          <iframe src={project.previewUrl} loading="lazy" title={project.title}></iframe>
                        </div>
                      </div>
                    )}
                  </>
                ) : (
                  <div className="mockup-placeholder">
                    <span>📄 请添加 preview.html</span>
                  </div>
                )}
              </div>
            </div>
            <div className="works-page-num">{index + 1} / {projects.length}</div>
          </section>
        );
      })}
    </div>
  );
}
```

## 6. 使用流程

### 6.1 第一次准备
1. 在项目根目录运行 `npm install`（确保依赖完整）。
2. 运行 `npm run generate-works` 生成初始的 `manifest.json`（此时可能为空）。
3. 启动开发服务器 `npm run dev`，访问 `/works` 页面，应看到骨架屏，随后显示空状态引导。

### 6.2 添加新项目
1. 在 `public/works-data/` 下新建一个文件夹，命名与项目相关（例如 `todo-app`）。
2. 在该文件夹内创建 `meta.json`，格式如下：
   ```json
   {
     "title": "项目标题",
     "subtitle": "副标题或简短描述",
     "description": "详细的项目介绍，支持多行。",
     "techStack": ["React", "Node.js", "MongoDB"],
     "displayType": "browser",   // 或 "mobile"
     "demoUrl": "https://demo.example.com",
     "githubUrl": "https://github.com/yourname/repo"
   }
   ```
3. 创建 `preview.html`，这是您项目的 UI 预览页面。**注意**：该页面内的资源引用建议使用绝对路径（以 `/` 开头），因为 iframe 的基准 URL 是 `public/works-data/项目名/`。
4. （可选）添加 `cover.png` 作为封面图。
5. 运行 `npm run generate-works`。
6. 刷新页面，新项目即出现在作品列表中。

### 6.3 删除或修改项目
- 直接删除或修改 `public/works-data/` 下的对应文件夹，再次运行 `npm run generate-works` 即可更新清单。

---

## 7. 注意事项

- **`preview.html` 独立性**：该页面会被嵌入 iframe，建议保持自包含（内联 CSS/JS 或使用 CDN），避免依赖外部未加载的资源。
- **路径问题**：预览页面中引用图片等资源时，请使用 **绝对路径**（如 `/images/logo.png`），因为 iframe 的当前路径是项目子目录，相对路径可能失效。
- **环境变量**：无需额外配置，`fetch('/works-data/manifest.json')` 在开发和生产环境均可正常工作（`public` 目录下的文件被映射到根路径）。
- **构建部署**：运行 `npm run build` 时，`public/works-data/` 下的所有文件（包括生成的 `manifest.json`）都会被复制到构建目录，无需额外配置。
- **脚本语言**：`generate-works.js` 使用 CommonJS，可在 Node.js 中直接运行。若您项目启用了 `"type": "module"`，请将脚本改为 `.cjs` 扩展名或在 `package.json` 中指定 `"type": "commonjs"`。

## 8. 后续扩展建议

- 可添加**分类筛选**或**搜索**功能（在 `Works.jsx` 中增加过滤逻辑）。
- 可给 `meta.json` 增加更多字段（如 `featured`、`date`），并在页面中展示。
- 若项目数量增多，可考虑**懒加载** iframe（当前已使用 `loading="lazy"`）。
